# Protocol

EXP0 base, EXP1 vanilla DPO, EXP2 target generation, EXP3 target condition, EXP4 full TL-DPO, EXP5 full TL-DPO random mask. Dùng cùng split/frame sampling; chọn hyperparameter trên validation, giữ test cho báo cáo cuối. Khi coverage verified khác nhau phải báo cáo matched subset và sample count.
